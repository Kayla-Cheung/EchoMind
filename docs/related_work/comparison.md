# Related Work Comparison Matrix

此表用于比较研究设计和可迁移的证据；“与 EchoMind 的关系”是项目分析，不等于原作者提出的结论。

| Citation key | 研究对象与任务 | 观测变量 / 验证方式 | 主要发现（概括） | 与 EchoMind 的关系 / 边界 |
| --- | --- | --- | --- | --- |
| [constans1999](papers/constans1999.md) | 高低社交焦虑学生；模糊人际与非人际事件解释 | 对模糊刺激的解释偏差 | 高社交焦虑组在人际模糊事件中较少给出积极解释；效果呈内容特异性 | 提醒保留积极率及非社交对照；不是 Agent 生成文本的验证研究 |
| [miers2020](papers/miers2020.md) | 324 名 18–25 岁青年；线上、线下社交情境 | 解释偏差、社交焦虑、受欺负经历与回避的关联 | 在线和线下解释偏差与社交焦虑相关，在线偏差与在线回避等变量有独特关联 | 支持同时研究解释与行动意向；关联结果不能直接当作因果效应或自由生成输出基线 |
| [gao2025](papers/gao2025.md) | 人类与 LLM；11–20 money request game | 决策分布、人类匹配度、提示与模型敏感性 | 在该经济博弈中，多种 LLM 设置未能可靠重现人类行为分布 | 要求实际的人类分布对照和稳健性检验；不是社交焦虑任务 |

## 待纳入研究时的最少字段

- Citation key、DOI / URL、任务与参与者/Agent、实验操纵、输出格式、核心指标
- 是否有真实人类对照；比较的是方向、效应量还是完整分布
- 是否存在留出情境、跨提示/模型/时间稳健性与独立标注
- 原论文局限、EchoMind 可借鉴之处、不能直接类推之处

## 与实验文档的职责分界

本表记录**外部证据的横向比较**；具体假设、版本、流程与分析计划仍在 `docs/state.md`、`docs/mechanism.md`、`docs/ablation.md`。不要在两处维护互相矛盾的实验协议。
