# Related Work

EchoMind 的文献工作按**证据所回答的问题**组织，而不是按阅读顺序组织。本目录用于协作整理研究依据，不代表项目已验证心理状态模拟或能够替代人类被试。

## 1. Human psychological evidence

研究人类在模糊社交情境中的解释倾向，以及焦虑相关的行动/回避意向。

- [Constans et al. (1999)](papers/constans1999.md)：高、低社交焦虑参与者对模糊事件的解释差异；特别注意积极解释减少与情境特异性。
- [Miers et al. (2020)](papers/miers2020.md)：线上/线下解释偏差与社交焦虑、回避等变量的关联。

**对 EchoMind 的启示：** 分开报告积极、中性、消极和不明确解释；社交与非社交情境分别分析。人类量表结果不直接等于 Agent 自由文本类别比例。

## 2. LLM-based human simulation

这一部分收集用 LLM/Agent 生成或预测人类心理与行为数据的研究。新增文献时，应注明是否使用记忆、角色设定、动态交互、真人对照，以及生成输出的形式。

当前尚未在本目录纳入能够证明 EchoMind 所设机制有效的直接复现论文；不要从“模型能被提示影响”推导出“模型具有人类焦虑”。

## 3. Validation and evaluation

- [Gao et al. (2025)](papers/gao2025.md)：在经济决策任务中检验 LLM 作为人类行为替身的局限，提示必须比较实际分布并检验稳定性。

**对 EchoMind 的启示：** 区分上下文诱导效应与对真人数据的预测效度；冻结方案后在未调参的情境中比较完整类别分布，同时报告无记忆基线、编码一致性和失败结果。

## 4. 研究定位与未解决问题

现有三篇文献分别提供人类任务依据和一般性的模型效度警示，**尚不能证明**：

1. 记忆条件能稳定诱导与不同人类焦虑水平相对应的 Agent 反应；
2. 文本行动意向等价于人类实际行为；
3. 由独立 LLM 编码得到的标签具有充分人类一致性；
4. 效果能够迁移到新情境、新模型和新采样批次。

EchoMind 目前首先研究固定情境与模型时，记忆条件对解释、行动文本分布的影响；后续才研究它与独立人类参照数据的匹配程度。具体方案以 [state.md](../state.md)、[mechanism.md](../mechanism.md) 和 [ablation.md](../ablation.md) 为准。

## 5. 协作维护约定

- 新增论文时，在 `papers/` 中新增 `authorYYYY.md`，并在 [comparison.md](comparison.md) 与 [references.bib](references.bib) 中补充相同的 citation key。
- 单篇笔记区分论文**实际结果**、研究者**解释**和对 EchoMind 的**建议/假设**。
- 引用原论文 DOI 或永久链接；不在仓库中存放无法确认再分发许可的论文 PDF。
- 统一通过独立分支和 Pull Request 审核引用准确性；改动现有实验协议需单独说明，不以文献更新暗中修改实验配置。
