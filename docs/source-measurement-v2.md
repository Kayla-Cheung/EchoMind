# 来源对照 v2：本轮优化与使用教程

更新：2026-10-22。入口：<http://127.0.0.1:8769/#measurement>。协议：`memory-source-v2`；材料：`source-materials-v1`；统计约定：`source-descriptive-v1`。

## 目的与设计

旧实验已经观察到记忆条件下的编码差异，但自身经历与他人材料、输出要求和编码误差没有充分分离。本轮实现可运行的来源对照，不追求提高负面回答率。

四组为自己／他人 × 平稳／不利经历。同一效价下，事件正文逐字相同，只改变资料卡中的经历主体。固定身份和当前情境，每次使用独立上下文。两个材料包与四个情境均由研究者编写，是开发材料；效价、相关性及近／远分类尚未独立验证，不能称为已验证刺激或封存评估集。

两个默认方案保持原版本文字：`agent-minimal-v2.0` 自然接续；`agent-standard-v2.0` 回答当前理解和下一步。共同编码为 `blind-multiaxis-v3.0`。新运行器实际使用所选版本构造输入。旧 bundle 元数据中的“仅预览”保留为历史版本内容；可运行性由本次新协议提供，不改写原 bundle。A/B 同时改变提问要求，不是纯格式标签消融。

## 简单操作

1. 双击 `start_audit_windows.bat`，打开工作台的 **来源对照 v2**。
2. 初次使用点 **快速检查 · 8 条**，再点 **预览配置与完整 Prompt**。检查四组资料卡、提示版本和编码器输入。
3. 点 **运行已预览的 MOCK**。MOCK 不访问模型、不产生费用；四组使用相同样例分布，D=0 是流程预设，不是科研结果。
4. 在下方查看分层结果、原回答、逐字证据及实际 Prompt，导出 JSON/CSV。页面刷新恢复查询；服务重启保留结果，未完成任务标为中断，不自动续跑。
5. 完成盲评及材料检查后，再选 **研究配置 · 192 条**：4 条件 × 2 方案 × 4 情境 × 2 材料包 × 3 次重复。真实运行另需 192 次编码，合计 384 次逻辑调用，传输重试另计。这只是可行性规模，不保证统计功效。

当前服务保持离线，真实模式不可选。本轮没有执行付费实验。未来普通联网服务中，须由用户选择真实模式、预览配置、核对调用数量并勾选确认后发起。新编码器的供应商线上兼容性尚未实测。

修改提示：到 **Prompt 与研究** 保存新版本，回到本页点 **刷新提示版本** 后选用。每批最多选两个版本，必须使用同一份编码规则。修改配置使旧预览失效，服务器也核验配置哈希。每条记录保存材料、提示 bundle、模型配置、调度种子和实际输入；调度种子不是模型采样种子。旧协议继续使用旧规则。

## 先做现有回答的盲评

在 **历史与分析** 分别打开原 A `820cb1f4` 和 B `46c4575c`，下载 **空白归因盲评表**，共 84 条。失败但保存了非空角色回答的记录也可从相应批次导出；没有回答的认证失败不生成空样本。

- 两名编码员分别取得随机排序副本，不看条件、模型和旧标签；用相同 `case_id` 对齐结果。
- 填写 reviewer_id；`negative_attribution` 与 `benign_attribution` 分别取 `present / absent / uncertain`。present 必须在 evidence 列复制原文引文。两者可以同时 present。
- “他忙，也可能不想理我”：两维 present；“我难过”：情绪不等于归因；“是不是我说错了”：结合当前事件的因果含义判断，不把任何自我评价都算负面归因。
- 映射 JSON 由研究者保管，不给编码员。回答本身仍可能泄露材料；这是实验元数据遮蔽，不是保证无法猜组，也不是权限隔离。
- CSV 校准主要归因维度，行动及其他维度仍需另行标注。先比较独立判断、一致性、分歧和条件效应，再裁决。空表和人工审核模型回答都不是人类心理实验数据。

本轮提供导出和映射，尚未实现人工标注回导或一致性统计页面，也没有真实人工复核结果。原标签不改变。

## 如何读结果

新编码独立记录不利归因、非不利归因、负面情绪、明确记忆连接、多行动及时间／承诺程度。所有 present 与行动引文校验是否逐字出现在回答中；这能排除编造引文，不能证明语义判断正确。编码器只接收当前情境与本次回答。

主要分母为非空角色回答。页面分别报告已确认不利归因数、未知数、编码失败、未返回回答及未发出任务。未知包含 uncertain 与编码失败，不是确定的 absent。比例范围把未知分别按 absent 与 present 计算，**不是置信区间**。其他维度和行动也只是已编码内容的确认数，不能把未编码样本解释成没有这些行为。

仅当四个条件的预定重复全部完成、无失败且不利归因都可判断时，计算：

`D = (不利自己 − 平稳自己) − (不利他人 − 平稳他人)`

按模型与参数、编码器、提示版本、材料和情境分别计算，不合成一个比例，不给 p 值或“claim 成立”徽章。D>0 至多提示来源条件化差异，仍可能来自人物叙事规则；D=0 或反向也保存。重复调用不是人类参与者，不能代替更多独立情境。

立即回避只计 `withdraw + now + done/decided`；条件性回避另列。放下手机、沉默或未行动不自动算回避。人类文献参考仍保留在原机制页，与这里的生成比例不可直接比较。

## 数据与验证

使用现有 SQLite 表和独立协议字段，未迁移 schema 或重写旧记录。修改前备份及哈希清单在 `data/`。新批次进入统一历史；JSON 保留全字段，CSV 附加多维字段及完整记录。旧分析接口排除新协议。

认证失败、重试后限流及连续失败仍停止后续调度。刷新仅恢复查询，不重复提交运行；可从服务器找回浏览器未保留 ID 的任务，服务重启不自动续跑。
