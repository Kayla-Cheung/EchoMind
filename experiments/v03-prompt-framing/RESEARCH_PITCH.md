# 面向导师的短提案：经历条件效应还是测量产物？

## 一句话问题

**固定基础模型后，自我经历材料对模糊社交情境的解释影响，能否在控制相同语义材料、测量格式与编码误差后，迁移到新情境？**

拟题：*Separating Narrative Priming from Generalizable Interpretation Bias in Memory-Conditioned LLM Agents*。

研究对象是可观察的条件输出分布；心理相关偏向是需要外部验证的行为模式；内部焦虑、情绪体验及临床状态不在本项目现阶段的证据范围内。

## 已有证据及价值边界

- A：DeepSeek、同题三材料条件，各 20 次；旧自动编码不利归因 4/20、5/20、19/20，回避 0/20、0/20、1/20。可以说明特定条件下输出/编码分布变化；无法排除叙事启动与编码伪差。
- B：4 种材料来源 × 2 格式，每格 3 次；自己不利组三通道 3/3 negative，自由叙述 1/3。是测量反应性的线索，不是稳定交互或心理机制证据。
- MiniMax：60 次中 57 条成功、3 条格式失败；可提供有限的第二模型线索，不能当作完整预设复现。
- 认证失败与 MOCK 不是 Pilot 证据。修复期间出现的 958e4338（60 条）与 bc6d3dec（24 条）批次单列，不能反过来补强原 A/B 的“预注册”地位。

科研价值目前在于：已有可追溯实验平台与可审计反例，可以将一个表面成立的效应拆解成生成、格式、编码和来源归属的贡献。单独“负面 Prompt 产生更多负面文本”创新性较弱。已有实验用 LLM 复现人类行为任务，也发现系统性失真。[Aher et al., ICML 2023](https://proceedings.mlr.press/v202/aher23a.html)

近期研究已展示情绪叙事引发 Agent 决策变化，因此不应宣称首次发现情绪上下文影响行为。[Ben-Zion et al., 2026](https://doi.org/10.1038/s44387-026-00122-1) 更具体的差异化是**测量有效性、来源×效价的匹配对照、跨语义情境迁移及反例**。

## 最小近期研究（先做校准，再生成）

第一步不需要付费 API：用已导出的 A/B 84 条回答做双人独立盲复核。随机 ID 隐藏组别与旧标签；先冻结新 codebook，再评估每维混淆矩阵、一致率、κ及分歧。引文校验不能取代人工。原标签保留；这一阶段明确称事后测量审计。

第二步是新数据的小规模可证伪实验：

| 因素 | 设计 |
|---|---|
| 归属 × 效价 | 自己/他人 × 平稳/不利，共 4 条件；事件正文相同，仅来源卡改变 |
| 测量格式 | A 最小干预、B 标准化两方案 |
| 情境 | 4 个新情境：2 个语义较近、2 个语义较远；都不使用旧 S01；其中预先封存的评估题在冻结设计前不用于调提示 |
| 材料 | 2 套独立事件包；内容、长度与相关性由人工预审 |
| 重复 | 每格 3 次；共 4×2×4×2×3 = **192 条角色回答**，另 192 次编码，即最多 384 次逻辑调用，不计有上限的传输重试 |
| 模型 | 先固定一个模型与采样配置；这是可行性阶段，不能保证统计功效 |
| 主要指标 | 新版不利归因 present 及 uncertain 的预设处理；同时报告生成/编码缺失；不使用文本情绪负面率代替归因 |
| 主对照 | D = (不利自己−平稳自己) − (不利他人−平稳他人)，分别报告每种格式、材料与情境；不先混成一个比例 |

当前没有执行此实验，也不因本提案而自动发起调用。实测耗费依模型、输入长度、重试而异，调用数不是费用报价。

**可证伪预测**：自传式归属若比一般内容启动多提供稳定行为信息，D 应在预留情境中保留预先规定的方向，并且不能只依赖三通道或一个材料包。若相同效价在自己与他人条件产生相近变化、效应只出现在词义近的题、换格式/人工编码就消失，则来源特异性假设不获支持。出现反向或零差异也如实报告；n=3 的宽区间不能证明不存在效应。

不把上述 D>0 当作焦虑机制已被证明；人物归属叙事本身仍可产生 D。无经历、非社交负面和来源卡顺序是后续必要扩展，用于解释绝对基线和更宽的机制，最小阶段先不承担所有构念主张。

## 从 Pilot 到正式课题

1. 冻结版本、主对照、最小有意义效应和失败处理；用小样本校准数据做预算/精度规划，正式评估使用新题新材料。不能把重复调用数当跨情境样本量。
2. 增加足够情境与材料包后，按情境/材料分层估计效应，使用层级模型或按这些单位重采样的区间；正式样本量据聚类结构规划。四个情境不足以支持精细总体方差估计。
3. 在第二、第三模型上独立复现，记录版本日期、采样参数、有效率与同样的人工校准；不共享模型专用调优过的评估题，不用统一百分比掩盖模型差异。
4. 加入一次标准化反馈，测量解释修正与实际行动选择；将预测和行为意向、已执行动作区分。无论解释是否改变，都允许行动不变。
5. 人类比较采用同题同任务与同编码，而非拿论文组均值对齐模型采样率。先复现一种现成范式，再研究材料操纵；把人类量表分组和模型记忆条件当成不同自变量，不能直接一一对应。

文献均值相似并不保证变异、相关结构和子群有效性，这是模拟调查研究已经暴露的问题。[Bisbee et al., 2024](https://doi.org/10.1017/pan.2024.5) 当前 UI 文献卡仅保留背景用途。

## 可能的计算机科学贡献

- 一个带来源、格式、情境和编码版本的可复核评价集，区分真实生成差异和判分变化，发布负例与不成立的条件。
- 一套独立多维归因/行动标注与证据校验方法，报告人机编码误差对组效应的传播，而非只比较分类准确率。
- 第二阶段可研究记忆检索算法是否选择性放大某类经历，并测量下游行动变化；这比继续增加“焦虑 Prompt”更贴近 Agent 系统研究。

近期向导师汇报应带：原始 A/B 对照、三个可复核编码反例、84 条盲评材料、192 条新实验设计表，以及明确的失败判据。无需先承诺顶会或人类心理模拟成功。
