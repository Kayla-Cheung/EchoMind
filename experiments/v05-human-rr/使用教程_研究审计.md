1. 双击 **启动EchoMind.bat**（或 **start_audit_windows.bat**），打开 <http://127.0.0.1:8769/>。这是离线模式：可以看历史、做 MOCK，不读取密钥、不调用付费模型。若提示另一目录占用端口，退出那里的服务后再启动。
2. 首页 **历史与分析** 默认列出全部批次，包括失败和 MOCK。可按北京时间日期、模型、协议和状态筛选；点击批次前八位 ID 查看整批结果。实验 A 为 **820cb1f4**，B 为 **46c4575c**，MiMo 60 条失败为 **cd574596**。
3. 在逐条记录里展开 **角色完整 Prompt**、**编码器 Prompt / 原始输出** 或 **完整原始记录**。上方可并列选另一批次，但不合并统计。JSON 保留全部字段；CSV 也包含完整记录 JSON。
4. 要恢复其他文件，在历史页底部选 JSON → **预览导入** → 确认新增/重复/冲突 → **确认导入**。相同内容跳过，冲突整份拒绝；实际写入前自动备份。没有原始回答的汇总文件不能还原实验。
5. **Prompt 与研究** 可阅读审计、提案及 EchoMind 调研。选择新方案 A/B，点 **离线验证并预览**。修改 JSON 时填写新的 `version` 再保存；修改编码文本也需新 `coder_version`。这些是草案，保存不会改变旧实验、重编码历史或启动模型。

要体验旧实验流程，切到“经历强度对比”或“记忆归属 × 输出格式”，保持 MOCK 后运行。新 MOCK 会保存到当前数据库，并明确标为 `MOCK_NOT_LLM`；科研验收自动测试会使用临时库。

原始机器标签不等于人工金标准；论文人类数据卡在“经历强度对比”内，仅供参考。原 A/B 的盲复核空表在 `data/research-audit/blind-review-84.csv`，不要向编码员提供旁边的映射文件。
