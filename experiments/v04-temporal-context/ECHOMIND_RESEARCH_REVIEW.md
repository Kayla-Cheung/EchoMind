# EchoMind：科研价值、相关研究与深化路线

检索与仓库核查日期：2026-10-21。审阅的公开提交：[`8d8765967a8d7d088c1043f5c5b0be6cd35fde10`](https://github.com/Kayla-Cheung/EchoMind/commit/8d8765967a8d7d088c1043f5c5b0be6cd35fde10)。本报告基于公开代码与论文，以及本地 SOS 历史数据审计；没有修改、运行或发布远程仓库。

## 判断

**值得继续，但需要把主贡献收窄为“记忆条件下心理相关行为的测量与泛化边界”。** 当前工作足以成为一个有证据的研究起点，还不足以作为“Agent 已模拟人类焦虑”的结论。

| 层次 | 目前可成立的价值 | 尚缺什么 |
|---|---|---|
| 工具与可复现性 | 有协议、独立上下文、顺序随机化、Prompt hash、原始回答、失败留存与历史分析 | 公开 README、冻结的实验配置、脱敏原始数据、可复跑分析及清晰的研究主张 |
| 经验性发现 | 本地旧数据展示记忆条件与编码结果的关联；格式消融暴露测量敏感性 | 独立编码可靠性、新材料新情境复现、来源/语义的匹配对照 |
| 论文贡献 | 有机会形成测量方法、诊断基准或 Agent 记忆检索偏差研究 | 不能停留在“输入更负面，输出更负面”，也不能凭重复次数变大替代构念效度 |

这是一项条件性判断，不是对录用概率或会议档次的保证。负结果也可能有价值，前提是预先定义了可证伪预测，排除了明显测量错误，并说明失效的适用范围。

## 从实际仓库看到什么

1. [机制协议](https://github.com/Kayla-Cheung/EchoMind/blob/8d8765967a8d7d088c1043f5c5b0be6cd35fde10/docs/mechanism.md) 的准确 claim 是固定人物、模型、问题后经历条件改变回答比例。重复是新的独立 API 上下文。这测量条件生成分布，尚不是一个连续生活、有记忆更新轨迹的 Agent。
2. [消融实现](https://github.com/Kayla-Cheung/EchoMind/blob/8d8765967a8d7d088c1043f5c5b0be6cd35fde10/echomind/ablation.py) 包含正面自己、负面自己、负面他人、无记忆，缺少正面他人，因此不是完整的效价×来源因子设计。
3. [实际提示](https://github.com/Kayla-Cheung/EchoMind/blob/8d8765967a8d7d088c1043f5c5b0be6cd35fde10/echomind/prompts.py) 中的他人条件同时改导语和全文人称；格式条件同时改篇幅与行动措辞。观察到差异不能唯一归因于心理因素。
4. 编码把负面与非负面混合解释归 neutral，三通道排除说话中的行动；这些规则会改变哪些内容被算进结果。只有“不把分组告诉 judge”不足以保证测量可靠。
5. [新版模板](https://github.com/Kayla-Cheung/EchoMind/blob/8d8765967a8d7d088c1043f5c5b0be6cd35fde10/echomind/prompt_registry.py) 已有 A/B 与多维编码草案，但 [runner](https://github.com/Kayla-Cheung/EchoMind/blob/8d8765967a8d7d088c1043f5c5b0be6cd35fde10/echomind/runner.py) 仍只运行旧协议；不能把模板存在说成已验证。
6. 该提交主树没有 README、实测数据集或正式结果报告。A/B 数字来自已审计的本地 SOS SQLite，**不是从 EchoMind GitHub 数据复核得到**。本地修复不能自动等同远端仓库已同步所有更新。

现有最值得研究的异常不是“负面率太低”，而是：同样主题的负面文本，在不同格式/编码规则下会得到很不一样的测量；解释变了，行动可能不变。这两点能催生可证伪的问题。

## 相关工作如何改变创新性判断

下面是针对项目关键问题的定向检索，不是穷尽式系统综述。Nature 部分页面直接打开受访问限制，已通过其公开检索文本、作者机构版本或正式 DOI 核验；不声称逐页读完所有论文。

| 相关研究 | 已经做到了什么 | EchoMind 应怎样与它区分 |
|---|---|---|
| [Aher et al., ICML 2023](https://proceedings.mlr.press/v202/aher23a.html) | 用既有人类实验检验 LLM 行为模拟，并发现某些任务中的系统性失真 | 不能以“用 LLM 做心理/社会实验”为创新点；需具体解释何时复现、何时失效 |
| [Sclar et al., ICLR 2024](https://arxiv.org/abs/2310.11324) | 在特定模型与任务中展示提示格式敏感性 | 格式须成为评价设计因素，不能只展示某一种格式下的大效应 |
| [Hua et al., EMNLP 2025](https://aclanthology.org/2025.emnlp-main.1006/) | 显示部分被称作提示敏感性的变化来自评分方法 | 不应预设所有差异都发生在生成模型；本项目还须检验 judge 本身的误差 |
| [Serapio-García et al., Nature Machine Intelligence 2025](https://doi.org/10.1038/s42256-025-01115-6) | 将可靠性、聚合/区分/效标效度用于部分配置下的合成人格测量 | 单一 negative 比例远不足以建立心理构念；借鉴验证逻辑，不照搬人类量表阈值 |
| [Wekenborg et al., Lancet Digital Health 2026](https://pubmed.ncbi.nlm.nih.gov/42270468/) | 已研究多模型的情绪诱导、调节及相关文本偏向 | “诱导后文本更负面”已有直接相关工作；应把叙事、测量和泛化对照做得更可识别 |
| [Ben-Zion et al., npj Artificial Intelligence 2026](https://doi.org/10.1038/s44387-026-00122-1) | 三模型、多叙事的购物任务中，叙事启动关联可观察决策变化，并有中性叙事对照 | “情绪上下文改变 Agent 行动”也非空白；自身/他人匹配、跨任务边界和系统级检索是更具体的问题 |
| [Park et al., arXiv 2411.10109v3，2026 修订](https://arxiv.org/abs/2411.10109v3) | 用真实个体访谈/问卷构造 Agent，并对保留题比较个体预测与人的重测基准 | 人类相似性应有匹配对象和外部预测，不是拿不同论文的组均值对齐；旧版常见“85%”也不是普遍绝对准确率 |
| [Wang et al., Findings ACL 2026](https://aclanthology.org/2026.findings-acl.1175/) | 将角色记忆利用分解为定位、选择、边界与实施，并提出评测 | 记忆驱动角色扮演已有细分框架；本项目可问记忆选择如何系统性改变归因/行动，而不只问角色知识是否答对 |

这些结果不共同证明模型具有人类焦虑。类似输出、心理相关行为规律和内部状态是不同证据层级。关于模拟调查的研究也提醒：均值接近时，方差和相关结构仍可能明显失真。[Bisbee et al., 2024](https://doi.org/10.1017/pan.2024.5)

## 五个可继续深化的方向

### 1. 测量伪差与行为差异分解——近期优先级最高

问题：记忆条件效应有多少来自角色输出，有多少来自格式和编码器？

做法：双人独立盲评旧 A/B 全部 84 条；原格式文本与仅删除标签、保持正文不变的副本分别编码，编号随机、不让同一编码员立即看到配对。再把同一批原文交给不同固定 coder，比较条件效应而不只比逐条一致率。原文保持不变，只改评判展示，才可识别判分环节的贡献。不能用另一模型重新“润色”正文作为等价副本。

指标：每维混淆矩阵、标注一致性、因格式而发生的标签翻转、条件效应对 coder 的敏感性、格式/缺失率。必要时报告各测量方式的效应区间，不计算一个不稳定的“伪差占比”比值。

可证伪结果：若格式删除后人工判断保持、自动结果剧烈改变，主要疑点在测量；若独立编码也确认语义变化，则生成差异更可信。两者可以同时存在。

贡献形态：心理模拟任务的测量稳健性基准与错误分类。成本低，可直接利用现有原文，适合先做。

### 2. 自传式归属效应能否超出语义启动——最佳下一组生成实验

问题：相同不利事件属于“我”与“他人”时，效应是否不同？这种差异能否出现在语义距离较远的社交情境？

做法：补齐自己/他人 × 平稳/不利，事件正文完全匹配，仅来源卡改变；跨两种测量方案、两套独立材料和多个保留情境。主要对照用效价差值的来源交互 D，而不是只比负面自己与无文本基线。另设来源顺序对照以检验显著性和长度的影响。

可证伪结果：如果他人材料同样有效、只在词义重叠场景有效，或只在强制心理独白时有效，就不支持“超出一般启动的稳定来源效应”。即使 D 存在，仍不能排除“遵循人物背景进行续写”；需将其称为来源条件化的行为泛化。

贡献形态：一个有明确替代解释和失效边界的经验研究。192 条小 Pilot 的具体布局见 RESEARCH_PITCH.md；正式结论需要更多独立情境及功效/精度规划。

### 3. 检索记忆是否放大偏向——最贴近 LLM Agents 的系统贡献

问题：同一个包含正负经历的记忆库，经不同检索策略选出的上下文，是否系统性偏向某类经历并改变后续决策？

做法：固定完整记忆库，比较随机检索、语义相似度检索、时间检索和预先规定的效价平衡检索；固定 k、token 预算、顺序和时间范围。保存被检索 ID、候选分数、最终上下文。先测检索分布，再测归因与任务行动；在相同检索结果下固定生成器，区分选择和生成环节。不要把“效价平衡”自动称为更像人。

指标：检索集合与原库的效价/主题差异、来源错误、下游归因变化、明确行动与任务完成率；比较稳健性和信息损失。可增加移除某条检索记忆的干预，但这只是系统因果作用，不是内部心理机制。

可证伪结果：若检索策略变化不改变选择分布或下游行为，则放大假设不成立；若改变行为却降低任务完成率，工程改进也不成立。

贡献形态：可审计的记忆选择诊断集、检索策略改进或测试方法。当前 EchoMind 直接注入材料，并未实现自主检索，所以这是新的系统研究阶段。

### 4. 新证据后的修正与行动——比持续输出负面词更有解释力

问题：在相同的模糊情境后，出现明确支持/反驳原解释的新信息时，记忆条件是否影响更新幅度、行动切换与迁移？

做法：预先固定反馈，不让生成器自编反馈；固定后续情境与时间窗。把“对方说正在考试”与“明确拒绝邀请”作为不同证据类型，控制可置信度；使用独立组或配对且顺序平衡的设计，防止前测本身诱导后测。观察输出概率/选择，不要求模型解释内部思维链。

可证伪结果：无论记忆条件，模型都能按反馈更新，说明原效应未必具有稳定性；若无关任务也一概变负面，更像一般启动而非社交特异模式。即使出现更新迟滞，也需要与人类同任务对照后才能称心理规律相似。

贡献形态：情境更新与行为一致性的动态基准。比一次输入一次输出更接近 Agent，但实现与统计成本较高。

### 5. 与人类同范式比较——长期主张必须补齐的一步

问题：模型是否重现同一任务中的条件效应、题目难度结构与归因—行动关系，而非只有平均负面率接近？

做法：从已发表解释偏向范式中选择一个，保留相同刺激和响应任务，核查材料使用条件及中文版本；另行采集或使用可获得的逐题人类数据。人类量表分组与模型材料操纵不是同一个自变量，应分开建模。若人类也接受材料操纵，则可比较同一干预对两种系统的效果。

评价：条件效应方向与大小、跨题排序、个体/重复测量变异、正负解释共存、归因与行动的联合关系、重测稳定性；预先固定相似性标准和有意义的等价界限，不能用“不显著不同”当作等价。

当前文献卡的 30%/59% 来自多题 WSAP 认可均值，不能与单题自由生成率直接相减。[Beard & Amir, 2009](https://pmc.ncbi.nlm.nih.gov/articles/PMC2792932/#T2) 即时消息研究也有未检出分组差异的结果，跨场景一致不是既定事实。[Goldman et al., 2025](https://link.springer.com/article/10.1007/s11031-025-10136-y)

贡献形态：经过人类数据校准的模拟有效性/失效边界研究；最接近长期目标，但不适合作为当前只有单题 Pilot 时的直接宣称。

## 建议的研究主线与停止准则

先做方向 1，随后做方向 2；如果测量稳定且出现跨材料的来源效应，再选择方向 3 或 4。方向 5 是提升为“人类心理规律模拟”所必需的验证阶段。此排序依据当前资源和识别问题，不是根据哪条路线最容易出显著结果。

不建议继续通过更强烈经历、直接“焦虑人设”、更严格地把疑问归负面来追求差异；不建议现在扩成十几个心理构念；不建议在少数模板重复上堆到上千次后宣称普遍心理规律。

三个清晰的停止/转向条件：

- 如果双人盲评不能可靠区分主要标签，先修测量，不扩模型调用。
- 如果差异只在一个 Prompt 或一个场景出现，将成果定位为提示/测量边界研究，保留反例。
- 如果来源交互消失而效价效应仍在，将结论降为语义上下文条件效应，转向记忆选择的工程影响。

近期可向导师交付的最小成果是：完整审计数据、冻结 codebook、84 条双人盲评、一个预先定义的来源×效价交互实验，以及跨格式/语义情境的结果矩阵。负结果同样进入矩阵。研究价值来自解释何时能信、何时不能信，而不是生成了多少像焦虑的句子。
