研究设计与学术边界声明

1. 探索性定位： 本工作台探讨的是“记忆注入策略对 LLM 在模糊情境中决策偏向的影响”，不声称拟合真实人类临床焦虑诊断或心理障碍。


2. 独立评判设计： 角色生成模型（Agent）与评估模型（Coder）严格隔离，评估器只看到情境与生成回答，不知道角色注入的记忆条件与研究假设，消除共谋偏见。


3. MOCK 与 REAL 隔离： 演示数据严格标明 MOCK（离线模拟流程验证）与 REAL（真实大模型 API 调用），绝不混淆证据链。
