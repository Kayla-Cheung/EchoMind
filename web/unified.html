CONTEXT INJECTION · DEMO 2

不同 Context 注入策略，会怎样影响同一模型的输出？

固定身份与模型 → 注入情境前缀 → 冻结输入消息 → 四个独立情境 → 公开解释、话语与行动意向 → 独立请求编码。

这里只检验受控模糊情境中的输出变化。快照保存可重放的输入，不要求形成持久记忆、心智状态或多 Agent 模拟。编码请求不参与情境互动。

无附加 Context 基线，加中性／负性 × 简短文本／静态记录／固定事件对话，共七组。默认 21 份输入快照、84 条最终决策。对话条件包含模型自生成回应、长度和消息位置等差异，比较的是整体注入策略；只做逐情境的探索性描述。
